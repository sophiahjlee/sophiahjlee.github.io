강사 소개 및 교육 개요
⏱ 00:00:02 ~ 00:03:57 ▶ 재생
🎯 학습목표
  • LED CONTROL 아키텍처의 기본 구조와 동작 원리를 설명할 수 있다.
  • Matrix LED 제어 방식과 그 필요성을 이해할 수 있다.
  • LED CONTROL 구조 변경(VER1.0→2.0)의 이유와 주요 차이점을 설명할 수 있다.
  • LED CONTROL 매니저의 역할과 제어 흐름을 이해할 수 있다.
📋 주요내용
  • 강의는 LED CONTROL, Input Manager, 거져 Manager, 오디오 등 총 6시간 동안 진행되며, 첫 번째로 LED CONTROL 아키텍처를 다룸.
  • LED CONTROL 매니저는 Matrix LED 제어를 위해 도입되었으며, 초기에는 App과 HAL이 단순 연결된 구조였음.
  • Matrix LED는 GPIO 포트 수의 한계를 극복하기 위해 사용되며, 여러 LED를 효율적으로 제어할 수 있음.
  • LED CONTROL 구조는 기존의 단순 연결 방식에서 기능 분리 및 확장(VER1.0→2.0)으로 변경되어, 신규 Device 추가가 용이해짐.
  • LED 제어는 스캔 라인과 데이터 라인을 이용해 60Hz 이상으로 빠르게 제어하여 사람의 눈에 깜빡임이 보이지 않도록 함.
  • LED CONTROL 매니저는 내부 구조의 문제점을 개선하여, 변경된 구조와 최종 적용된 매니저의 동작 방식을 설명함.
