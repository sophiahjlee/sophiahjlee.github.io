  3. Variable 및 LocalVariable 블록으로 변수를 선언하고 타입을 지정하여 코딩 블록 내에서 활용할 수 있다
주요내용7
  • images 폴더에 PNG를, image_sequences 폴더에 시퀀스 이미지를 복사하면 GUI Creator에서 자동 인식되며 Export 시 타겟 포맷으로 변환된다
  • ImageSequenceOpt 위젯: StartAnimation 블록을 호출해야 애니메이션이 재생됨. 일반적으로 onGrate(로드) 이벤트에 연결하여 스크린 생성 시 자동 시작한다
  • RepeatCount: -1(무한 반복) / n(n회 재생 후 onFinish 호출). RepeatCount=1로 설정하고 onFinish에 다음 ImageSeqOpt.StartAnimation을 연결하면 순차 애니메이션 체인을 구현한다
  • setCurrentFrame(n): 특정 프레임으로 즉시 이동. 이미지 시퀀스를 인덱스 기반 이미지 배열로 활용 가능 (예: 진행률 50% → 50번째 프레임 표시)
  • Variable: 워크스페이스 전역 변수. Variables 블록으로 선언하고 Set 변수명 블록으로 값 할당. onCreate에서 초기화 권장
  • LocalVariable: 특정 스코프의 로컬 변수. 연결된 블록의 타입이 자동 추론됨 (Number, String, Image 등)
