1. LUPA Studio 교육 개요

📌 학습목표

  • LUPA Studio의 기본 기능과 인터페이스를 이해하고 사용할 수 있다.
  • LUPA Studio를 통해 GUI 애플리케이션을 개발하고 빌드하는 과정을 수행할 수 있다.
  • LUPA 개발자 사이트에서 필요한 자료를 검색하고 활용할 수 있다.

📋 주요내용

  • LUPA Studio는 LUPA 애플리케이션 개발을 위한 IDE 환경으로, 코드 에디팅, 빌드, 설치 등의 기능을 제공한다.
  • LUPA Studio는 Visual Studio Code 기반의 Extension 형태로 제공되며, Windows와 Linux에서 사용할 수 있다.
  • LUPA 개발자 사이트에서는 애플리케이션 개발에 필요한 정보와 AI 챗봇 기능을 통해 지원을 받을 수 있다.
  • LUPA Studio의 주요 구성 요소로는 SDK Manager, Device Manager, Output Panel 등이 있으며, 각 요소의 역할을 이해해야 한다.
  • 애플리케이션을 빌드하고 실행하기 위해서는 프로젝트 설정, SDK 활성화, 타겟 디바이스 설정이 필요하다.
